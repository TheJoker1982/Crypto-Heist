Bitcoin Operations Mapping

Each Bitcoin operation maps to specific character sets for phonetic analysis:

Hash Operations (SHA256, RIPEMD160): Output is ALWAYS lowercase a-f
BSV Addresses: Use UPPERCASE A-F
Endpoint Rotation: -1 inverse offset at boundaries
Concatenation: Quiet concat with recursive matching
Boundary Detection: AA-FF markers process lowercase hash outputs
